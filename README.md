# SY Tiimi – Tekemisen laadun mittaristo

Staattinen HTML/CSS/JavaScript-sovellus, ei npm-riippuvuuksia.

## Julkaisu

1. Pura ZIP-tiedosto.
2. Vie kaikki viisi tiedostoa GitHub-repositorion juureen (ei ZIP-tiedostoa eikä ylimääräistä kansiota). Korvaa samannimiset tiedostot.
3. Tee commit. Jos GitHub on yhdistetty Verceliin, julkaisu käynnistyy automaattisesti.
4. Vercelin Framework Preset: Other; Root Directory: repositorion juuri; ei build-komentoa. Julkaisuhakemisto on `.`.

## Tiedostot

- `index.html`: lomakkeen HTML
- `styles.css`: ulkoasu
- `script.js`: pisteytys, valinnat ja yhteenveto
- `vercel.json`: staattisen julkaisun asetukset
- `README.md`: ohjeet

Paikallinen testaus: pidä kolme sovellustiedostoa samassa kansiossa ja avaa `index.html` selaimessa. Barlow-fontti latautuu Google Fontsista verkkoyhteydellä.
